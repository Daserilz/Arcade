#NOTE ตอนนี้ในเกมใช้ input ควบคุม player เป็นของจอยอาร์เคต
ถ้าต้องการเปลี่ยนเป็นการควบคุมด้วย keyboard ให้ไปที่ Prefab ของ player (p1,p2)
จากนั้นก็หา player input แล้วปรับที่ default scheme จาก Gamepad เป็น <Any> 
ซึ่งจะทำให้ ควบคุม player จาก keyboard ได้

keyboard control settings
---------------
Move : p1 WASD , p2 IJKL
interact : p1 E , p2 O
Dash : p1 Q , p2 U
